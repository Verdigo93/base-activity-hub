# Підготовка Base Activity Hub до запуску

Це **не публікація**, а перевірочний список для наступного етапу.

1. **Домен і хостинг.** Обрати домен і хостинг Node.js (Render, Railway, Fly.io або власний сервер), налаштувати HTTPS.
2. **Гаманець для платежів уже заданий:** `0x5F5d8B3Cf23368b9B5fab4e4A391A998803c292F`. ЦЮ Ж адресу треба передати у параметрі `treasury` при розгортанні NFT-контракту та фабрики, інакше виплати не перенаправляться. За успішну платну дію контракт має переказувати **0,10 USDC**. Приватні ключі не вводити.
3. **Тестова мережа.** Встановити Foundry, скомпілювати контракти, пройти тести, розгорнути на Base Sepolia та перевірити реальні сценарії через тестовий гаманець.
4. **Аналітика.** Створити API-ключ Etherscan V2 (звернути увагу на тариф для Base). Для детальної Dune-аналітики створити власний параметризований SQL-запит за адресою гаманця.
5. **NFT.** Замінити в `metadata/*.json` `REPLACE-YOUR-DOMAIN` на справжній HTTPS-домен; перевірити зображення та відображення NFT у гаманцях.
6. **Mainnet.** Лише після аудиту розгорнути перевірені контракти з офіційним USDC Base, прописати їхні адреси в `config.js`, протестувати мінімальною сумою.
7. **Base Dashboard.** Відкрити https://dashboard.base.org/ (раніше base.dev), зареєструвати застосунок, отримати Builder Code, вставити його в `config.js`, перевірити атрибуцію ERC-8021 за реальною транзакцією.
8. **Mini App.** Додати справжній маніфест із підписаним `accountAssociation` у `/.well-known/farcaster.json` згідно з поточними правилами Base/Farcaster, підтвердити домен і подати застосунок.
9. **Перед публікацією.** Налаштувати DNS, HTTPS, логування, rate limiting, резервне копіювання та сторінку умов/політики приватності. Перевірити mobile wallet, доступність і невеликі реальні транзакції.

**Потрібно від власника:** адреса treasury, домен, доступ до Base Dashboard для реєстрації, за потреби ключі Etherscan і Dune (вводити лише у серверному секретному сховищі).

**Поки не підключено:** повноцінний x402 facilitator + protected resource; інтегрований swap quote/router; QR WalletConnect для браузера без гаманця; аудит контрактів. У застосунку ці функції не видаються за готові.
