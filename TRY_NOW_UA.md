# Як зараз відкрити Base Activity Hub та підключити гаманець

**Поточна збірка:** локальний працюючий сайт. Публічного HTTPS-домену ще НЕ створено.

**На Windows (найпростіше):**
1. Встанови Node.js 20+ з https://nodejs.org/ (лише якщо ще не встановлений).
2. Розпакуй ZIP повністю в папку.
3. Запусти подвійним кліком `START_SITE_WINDOWS.bat` (не закривай вікно сервера).
4. Сайт автоматично відкриється за адресою **http://localhost:4173**.
5. Встанови MetaMask або Coinbase Wallet для Chrome, натисни **Connect wallet**, підтвердь підключення.
6. Баланс ETH/USDC та історія, доступна через API, почнуть оновлюватися. Для детальної історії потрібен серверний API-ключ Etherscan V2; без нього поля не вигадуються.
7. Можеш клацати всі картки, дивитися модальні вікна, NFT, завдання, змінювати мову та мережу. Саме підключення гаманця коштів не списує.

**Якщо хочеш перевірити реальні транзакції:**
- Для тестування без реального ETH переключись у **Base Sepolia** та отримай тестовий ETH у faucet.
- GM / Daily Check-in / Onchain Message працюють з переказом на власну адресу (0 ETH плюс газ) навіть до деплою контракту. Це реальні транзакції та списують мережевий gas.
- Перекази ETH/USDC — справжні, їх не потрібно тестувати з великими сумами; перевір адресу перед підписом.
- NFT mint і платний деплой зараз **заблоковані**, доки контракти не скомпільовані, протестовані та не розгорнуті на потрібній мережі. Не видаємо макет за запущений мінт.
- x402 і вбудований swap поки не підключено.

**Твій гаманець, який має отримувати комісію 0,10 USDC за мінт і деплой:** `0x5F5d8B3Cf23368b9B5fab4e4A391A998803c292F`.
Він внесений у `config.js` та всі інструкції до деплою. Самі смартконтракти зберігають адресу отримувача у конструкторі при розгортанні. Frontend перед схваленням USDC перевіряє її, токен оплати і фіксовану ціну. **Без деплою на мережі реальних виплат ще немає.**

**Для роботи з телефона або публічного URL:** потрібен реальний HTTPS-хостинг. Сам `localhost` відкривається лише на твоєму комп’ютері, а не в інтернеті.
